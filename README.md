# 想法集

这里装我的各种想法。

可以是产品点子、工程构想、工具需求、工作方式，也可以只是聊天时突然冒出来的一句「这个好像很爽」。不限于某个项目或某一类主题。

先记下来，慢慢讨论，允许修改、推翻和暂时没有答案。记录一个想法，不代表承诺把它做出来。

## 记录结构

- `topics/`：按主题整理的想法，简单想法可以直接放一个文件，内容多了再建目录。

第一篇来源记录：[关于 AI 编程工作室的最初对话](notes/2026-11-08-ai-development-studio.md)。

## 怎么继续记录

正文用中文，文件和目录名用英文。提交信息使用英文 Conventional Commits，例如 `docs: record an idea for an AI development studio`。

整理时区分「我的构想」「讨论中的建议」「还没决定的问题」，不把智能体的补充建议自动当作我的决定。不为记录想法强加开发排期和繁重模板。

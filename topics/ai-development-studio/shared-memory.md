# 共享记忆与协作

状态：核心愿望明确，具体机制待讨论。首次整理：2026-11-08。

## 我的构想

各台电脑可以共用记忆，而不是每台电脑各有一份互不相通的 `Memory.md`。

我希望在某个项目里已经说过的相关事情，其他团队需要时也能知道，不必在每台电脑前重新讲一遍。

## 讨论中的建议

以下是 48 提出的划分，尚未确定具体实现：

| 内容 | 可能记录什么 |
| --- | --- |
| 关于我的长期认知 | 偏好、沟通习惯、授权边界 |
| 项目知识与决定 | 架构边界、选择理由、已经否决的方案 |
| 当前任务状态 | 谁在做什么、当前进度、依赖与阻塞 |
| 可追查的证据 | 讨论来源、对应提交、测试环境和结果 |

共享记忆和实时任务状态可能需要配合：知道过去发生过什么，也知道现在谁正在做什么。

团队可以保留各自的临时调查空间；未经验证的猜测如果写进共享区，应让其他智能体看得出它的状态。共同知识需要能追查来源，也能在新事实出现后修正。

## 还没决定的问题

- 什么应该全局共享，什么只属于某个项目或一次任务？
- 多个智能体给出矛盾结论时，怎样保留分歧并判断？
- 什么情况下可以写入长期记忆，谁来确认重要决定？
- 如何知道旧记忆已经过期，或者只适用于某个代码版本？
- 机器离线、重连或者任务迁移时，如何补齐相关上下文？
- 凭据等敏感信息怎样与共享知识保持边界？

还没有选定数据库、检索方式、同步协议或记忆产品。
